# רבי נחמן מאומן 🕯️

אתר לשירים ולקליפים של רבי נחמן מברסלב, ולכל מה שחסיד שנוסע לרבינו צריך בדרך לאומן —
מסלולים דרך אירופה, מעברי גבול, קברי צדיקים, מדריך מעשי וצ׳ק ליסט.

האתר בנוי כאתר סטטי לגמרי: HTML, CSS ו־JavaScript בלבד. אין שרת, אין בנייה, אין התקנות.

---

## איך מוסיפים שיר 🎵

הוספת שירים היא פעולת ניהול בלבד — אין באתר שום מסך שמאפשר לגולשים
להעלות שירים או סרטונים. הכל נעשה מהמחשב, דרך כלי שאינו חלק מהאתר:

```bash
node tools/add-song.mjs https://youtu.be/XXXXXXXXXXX
```

הכלי שולף מיוטיוב את שם השיר ואת שם הערוץ, מנקה האשטגים מהשם,
מוסיף את השיר לראש הרשימה ב-`data/songs.js` ומוודא שהקובץ נשאר תקין.
אחר כך רק `git commit` ו-`git push`, והאתר מתעדכן לבד.

אפשרויות:

| דגל | מה הוא עושה |
|---|---|
| `--category "קליפים"` | קטגוריה לכל הקישורים ברשימה (ברירת מחדל: ניגונים) |
| `--title "שם"` | שם ידני, לקישור בודד |
| `--artist "מבצע"` | מבצע. ברירת מחדל: שם הערוץ ביוטיוב |
| `--no-featured` | לא להציג בעמוד הבית |
| `--end` | להוסיף בסוף הרשימה במקום בראשה |

אפשר גם להוסיף כמה קישורים בבת אחת:

```bash
node tools/add-song.mjs https://youtu.be/AAA https://youtu.be/BBB --category קליפים
```

ולערוך את [`data/songs.js`](data/songs.js) ישירות. כל שיר נראה כך:

```js
{
  id: "XXXXXXXXXXX",          // מזהה הסרטון ביוטיוב (11 תווים)
  title: "שם השיר",
  category: "ניגונים",         // מתוך window.SONG_CATEGORIES שבסוף הקובץ
  artist: "שם המבצע",
  year: "2026",
  words: "ליקוטי מוהר״ן ח״א, כ״ד",
  lyrics: "מילות הפזמון…",
  featured: true               // האם להציג גם בעמוד הבית
}
```

## הפרק על הברכות והישועות

העמוד `yeshuot.html` בנוי סביב מקורות בלבד: כל ציטוט בו הועתק מנוסח הספרים
ואומת מול המקור באתר ספריא, ולצידו מראה מקום וקישור ישיר לנוסח המלא.
מה שהוא מסורת או עדות אישית מסומן ככזה במפורש ולא מוצג כהבטחה כתובה.
לעריכה או להוספת מקורות — [`data/yeshuot.js`](data/yeshuot.js).

## הנגן

השיר מתנגן **בתוך העמוד עצמו**, במסגרת שיושבת בעמוד השירים ובעמוד הבית
(`<div id="player-slot">`). אין מודל, אין פופאפ, ולא צריך ללחוץ: ברגע
שהמסגרת נכנסת למסך השיר מתחיל לבד.

**למה הוא מתחיל מושתק:** דפדפנים אוסרים להתחיל שמע בלי מגע של המשתמש.
לכן הניגון האוטומטי מתחיל מושתק, ועל הווידאו מופיע כפתור "🔊 הפעל קול".
לחיצה אחת עליו פותחת את הצליל, ומאותו רגע כל השירים באותו ביקור
מתנגנים עם קול (הבחירה נשמרת ב-sessionStorage).

**כשגוללים או עוברים עמוד** הנגן מתכווץ לפינת המסך וממשיך לנגן, וחוזר
למסגרת כשחוזרים אליה. כדי שזה יעבוד, מעבר בין עמודי האתר אינו טעינה
מחדש: `assets/js/router.js` מביא את העמוד החדש ומחליף רק את התוכן שבתוך
`<main id="app">`, כך שה-iframe של הנגן לא נהרס באמצע השיר. כל כשל נופל
אוטומטית לניווט רגיל של הדפדפן.

בטעינה מלאה (רענון או כניסה ישירה לקישור) הנגן חוזר מאותה שנייה שבה עצר.
כשנגמר שיר, הבא ברשימה מתחיל אוטומטית.

## צפיות, לייקים ותגובות

בתחתית כל עמוד יש מקטע "מה אתם אומרים" עם מונה צפיות, כפתור לב ואזור
תגובות. הכל מנוהל בשירות ה-web-feeds:

```html
<script src="https://web-feeds.shayh22.workers.dev/embed.js" data-site="st_d3vwN5gI0ndI" defer></script>
```

כל עמוד נספר בנפרד לפי הנתיב שלו (`/songs.html`, `/route.html` וכו׳).

**נקודה שדרשה טיפול:** ה-embed נכתב לאתרים שנטענים מחדש בכל עמוד — הוא
סופר צפייה אחת לכל טעינת דף ושומר את הבקשה במשתנה פנימי. באתר הזה המעבר
בין עמודים אינו טעינה מחדש, ולכן בלי טיפול היה נספר רק העמוד הראשון בכל
ביקור, וכל שאר העמודים היו מציגים את מספר הצפיות שלו.
[`assets/js/feeds.js`](assets/js/feeds.js) פותר זאת: אחרי כל מעבר הוא
מזריק מחדש את תג הסקריפט, וריצה טרייה מאפסת את הספירה לעמוד החדש.

הצבעים של הווידג׳טים מותאמים לפלטה של האתר ב-`style.css`, תחת הבורר
`#feeds .tells-slot.tlx` — חזק מספיק כדי לגבור על גיליון הסגנון שהשירות
מזריק בזמן ריצה.

**כדי שהתגובות ייפתחו לגולשים** צריך להפעיל אותן להגדרות האתר בשירות
(`commentsEnabled`). כל עוד הן כבויות, מוצג "התגובות סגורות".

## עשרת המזמורים

פרקי התיקון הכללי מופיעים במלואם בעמוד "ברכות וישועות" — 164 פסוקים
בעשרה מזמורים, על לוח מוזהב עם דיו כהה ובגופן ספר מסורתי.

הנוסח הוא נוסח המסורה, ומוצג **עם ניקוד מלא ובלי טעמי מקרא** — כפי
שהתיקון הכללי מודפס בפועל בסידורים ובחוברות. הסיבה מעשית: גופני סת״ם
אמיתיים אינם כוללים סימני ניקוד וטעמים כלל, וטקסט מנוקד בגופן כזה נשבר.
לכן נבחר Frank Ruhl Libre — גופן הספר העברי הקלאסי, שמרנדר ניקוד נכון.

## קידום במנועי חיפוש ובמנועי AI

- `sitemap.xml`, `robots.txt` (מתיר במפורש את סורקי ה-AI), `llms.txt`
- קישור canonical ותגיות שיתוף מלאות בכל עמוד
- נתונים מובנים (JSON-LD): WebSite, Article, ItemList של הסרטונים,
  FAQPage שנגזר מהשאלות שבעמוד המדריך, ו-CreativeWork לתיקון הכללי

**הטמעת התוכן:** רוב תוכן האתר נוצר בזמן ריצה מקובצי `data/`. גוגל מריץ
JavaScript ולכן רואה אותו, אבל רוב הסורקים של מנועי ה-AI אינם מריצים —
ובשבילם העמודים היו כמעט ריקים. [`tools/prerender.mjs`](tools/prerender.mjs)
טוען כל עמוד בדפדפן וכותב את התוכן המוגמר בחזרה לתוך ה-HTML:

```bash
node tools/prerender.mjs
```

בטעינה אמיתית ה-JS מחליף את התוכן באותו תוכן עצמו, ולכן אין כפילות.
**להריץ אחרי כל שינוי בקובצי `data/`** — אחרת המהדורה המוטמעת מתיישנת.

**https://shayh22.github.io/rabbi-nachman/**

מה שצריך לעשות פעם אחת (בערך שלושים שניות):

1. להיכנס לריפו בגיטהאב → **Settings** → בתפריט הצדדי **Pages**.
2. תחת *Build and deployment* → *Source* לבחור **GitHub Actions**.
3. זהו. ה-workflow שב-`.github/workflows/pages.yml` רץ בכל push לענף הראשי
   ומעלה את האתר. הפרסום הראשון לוקח דקה־שתיים; אחרי זה כל שינוי עולה לבד.

לבדיקה שהפרסום רץ: לשונית **Actions** בריפו — שם רואים את ההרצה ואת הקישור לאתר.
