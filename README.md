# רבי נחמן מאומן 🕯️

אתר לשירים ולקליפים של רבי נחמן מברסלב, ולכל מה שחסיד שנוסע לרבינו צריך בדרך לאומן —
מסלולים דרך אירופה, מעברי גבול, קברי צדיקים, מדריך מעשי וצ׳ק ליסט.

האתר בנוי כאתר סטטי לגמרי: HTML, CSS ו־JavaScript בלבד. אין שרת, אין בנייה, אין התקנות.

---

## איך מוסיפים שיר 🎵

1. פותחים באתר את העמוד **הוספת שיר** (`add.html`).
2. מדביקים את הקישורים מיוטיוב — שורה לכל שיר. אפשר גם `youtu.be`, `shorts` או `embed`.
3. כותבים את שמות השירים באותו סדר, בוחרים קטגוריה ולוחצים **צור קוד**.
4. מעתיקים את הקוד ומדביקים אותו בתוך הסוגריים של `window.SONGS = [ ... ]`
   בקובץ [`data/songs.js`](data/songs.js).
5. שומרים, עושים commit ו־push — והשירים באתר.

אפשר גם לערוך את `data/songs.js` ישירות. כל שיר נראה כך:

```js
{
  id: "XXXXXXXXXXX",          // מזהה הסרטון ביוטיוב (11 תווים)
  title: "שם השיר",
  category: "ניגונים",         // מתוך window.SONG_CATEGORIES שבסוף הקובץ
  artist: "שם המבצע",
  year: "2026",
  words: "ליקוטי מוהר״ן ח״א, כ״ד",
  lyrics: "מילות הפזמון…",
  featured: true               // האם להציג גם בעמוד הבית
}
```

## מבנה הפרויקט

```
index.html        עמוד הבית — ספירה לאחור לראש השנה ושירים נבחרים
songs.html        כל השירים והקליפים, עם חיפוש, סינון ונגן
route.html        ארבעה מסלולי נסיעה לאומן דרך אירופה + קברי צדיקים
guide.html        מדריך הנוסע: מסמכים, כסף, גבול, סים, אוכל, לינה, בטיחות, מילון
checklist.html    צ׳ק ליסט הכנה שנשמר בדפדפן
add.html          כלי להוספת שירים מיוטיוב

data/songs.js     ← כאן מוסיפים שירים
data/route.js     ← כאן עורכים מסלולים, תחנות וציונים
data/checklist.js ← כאן עורכים את פריטי הצ׳ק ליסט

assets/css/style.css
assets/js/site.js       קוד משותף: ספירה לאחור, תפריט, הודעות
assets/js/songs.js      עמוד השירים והנגן
assets/js/route.js      עמוד המסלולים
assets/js/checklist.js  הצ׳ק ליסט והשמירה המקומית
assets/js/add.js        כלי הוספת השירים
```

## עדכון התאריך לשנה הבאה

בקובץ `assets/js/site.js`, בראש הקובץ:

```js
window.SITE_CONFIG = {
  roshHashanah: "2026-09-11T18:30:00+03:00",
  roshHashanahLabel: "ראש השנה תשפ״ז באומן",
  roshHashanahHuman: "…"
};
```

מעדכנים את התאריך והכיתוב — והספירה לאחור מתעדכנת בכל האתר.

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן. הכול עובד גם מהקובץ עצמו, בלי שרת.
מי שמעדיף שרת מקומי:

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000
```

---

## פרסום ב-GitHub Pages

בריפו: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
ה-workflow שב-`.github/workflows/pages.yml` מפרסם את האתר בכל push לענף הראשי.

לחלופין, אפשר לבחור `Source: Deploy from a branch` ולבחור את הענף — האתר סטטי לגמרי,
ולכן זה עובד גם ככה. הקובץ `.nojekyll` כבר קיים כדי שגיטהאב לא ינסה לעבד את הקבצים.
