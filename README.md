# רבי נחמן מאומן 🕯️

אתר לשירים ולקליפים של רבי נחמן מברסלב, ולכל מה שחסיד שנוסע לרבינו צריך בדרך לאומן —
מסלולים דרך אירופה, מעברי גבול, קברי צדיקים, מדריך מעשי וצ׳ק ליסט.

האתר בנוי כאתר סטטי לגמרי: HTML, CSS ו־JavaScript בלבד. אין שרת, אין בנייה, אין התקנות.

---

## איך מוסיפים שיר 🎵

1. פותחים באתר את העמוד **הוספת שיר** (`add.html`).
2. מדביקים את הקישורים מיוטיוב — שורה לכל שיר. אפשר גם `youtu.be`, `shorts` או `embed`.
3. כותבים את שמות השירים באותו סדר, בוחרים קטגוריה ולוחצים **צור קוד**.
4. מעתיקים את הקוד ומדביקים אותו בתוך הסוגריים של `window.SONGS = [ ... ]`
   בקובץ [`data/songs.js`](data/songs.js).
5. שומרים, עושים commit ו־push — והשירים באתר.

אפשר גם לערוך את `data/songs.js` ישירות. כל שיר נראה כך:

```js
{
  id: "XXXXXXXXXXX",          // מזהה הסרטון ביוטיוב (11 תווים)
  title: "שם השיר",
  category: "ניגונים",         // מתוך window.SONG_CATEGORIES שבסוף הקובץ
  artist: "שם המבצע",
  year: "2026",
  words: "ליקוטי מוהר״ן ח״א, כ״ד",
  lyrics: "מילות הפזמון…",
  featured: true               // האם להציג גם בעמוד הבית
}
```

## הפרק על הברכות והישועות

העמוד `yeshuot.html` בנוי סביב מקורות בלבד: כל ציטוט בו הועתק מנוסח הספרים
ואומת מול המקור באתר ספריא, ולצידו מראה מקום וקישור ישיר לנוסח המלא.
מה שהוא מסורת או עדות אישית מסומן ככזה במפורש ולא מוצג כהבטחה כתובה.
לעריכה או להוספת מקורות — [`data/yeshuot.js`](data/yeshuot.js).

## הנגן הצף

לחיצה על שיר פותחת נגן גדול במרכז המסך. סוגרים אותו בכפתור ⤢ והוא מתכווץ
לפינה וממשיך לנגן — גם כשעוברים בין עמודי האתר.

כדי שזה יעבוד באמת, המעבר בין העמודים באתר אינו טעינה מחדש: `assets/js/router.js`
מביא את העמוד החדש ומחליף רק את התוכן שבתוך `<main id="app">`, כך שהנגן
לא נהרס באמצע השיר. אם משהו נכשל — נופלים אוטומטית לניווט רגיל של הדפדפן.

בטעינה מלאה (רענון, או כניסה ישירה לקישור) הנגן חוזר מאותה שנייה שבה עצר.
דפדפנים חוסמים ניגון אוטומטי עם קול בלי לחיצת משתמש, ולכן במקרה כזה מוצג
כפתור "▶ המשך ניגון" במקום שהשיר יתחיל לבד.

כשנגמר שיר, השיר הבא ברשימה מתחיל אוטומטית.

assets/js/miniplayer.js הנגן הצף — שורד מעבר בין עמודים
assets/js/router.js     מעבר רך בין עמודים בלי טעינה מחדש
assets/js/songs.js      עמוד השירים והנגן
assets/js/route.js      עמוד המסלולים
assets/js/checklist.js  הצ׳ק ליסט והשמירה המקומית
assets/js/yeshuot.js    עמוד הברכות והישועות
assets/js/guide.js      מדריך הנוסע
assets/js/add.js        כלי הוספת השירים

## עדכון התאריך לשנה הבאה

בקובץ `assets/js/site.js`, בראש הקובץ:

```js
window.SITE_CONFIG = {
  roshHashanah: "2026-09-11T18:30:00+03:00",
  roshHashanahLabel: "ראש השנה תשפ״ז באומן",
  roshHashanahHuman: "…"
};
```

מעדכנים את התאריך והכיתוב — והספירה לאחור מתעדכנת בכל האתר.

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן. הכול עובד גם מהקובץ עצמו, בלי שרת.
מי שמעדיף שרת מקומי:

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000
```

## פרסום ב-GitHub Pages

כתובת האתר אחרי הפרסום:

**https://shayh22.github.io/rabbi-nachman/**

מה שצריך לעשות פעם אחת (בערך שלושים שניות):

1. להיכנס לריפו בגיטהאב → **Settings** → בתפריט הצדדי **Pages**.
2. תחת *Build and deployment* → *Source* לבחור **GitHub Actions**.
3. זהו. ה-workflow שב-`.github/workflows/pages.yml` רץ בכל push לענף הראשי
   ומעלה את האתר. הפרסום הראשון לוקח דקה־שתיים; אחרי זה כל שינוי עולה לבד.

לבדיקה שהפרסום רץ: לשונית **Actions** בריפו — שם רואים את ההרצה ואת הקישור לאתר.
